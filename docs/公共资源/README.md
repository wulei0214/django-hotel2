# PMS 项目公共资源说明

> 资源目录核对基线：57d2176b2dec821dd5c82ec71743603a42f44474（main，2026-11-12）。

## 目录内容
- 界面截图/：登录页、首页、预订抽屉、侧边栏等界面参考图。截图只证明某一时点的视觉状态，不证明接口、权限或业务逻辑已经验收。
- SQL与数据字典/：审计日志表结构/备份头等 SQL 参考。文件名含“非完整备份”的脚本不得作为完整数据库备份恢复。

## 使用规则
1. 截图必须标明来源版本或提交 SHA；若无法确认来源，标记为历史参考，不作为最新 UI 基线。
2. SQL 资源执行前必须确认数据库类型、目标库、权限、备份和是否具有破坏性；公共资源目录中的 SQL 默认只读参考，不代表已在 dev/生产库执行。
3. 不在公共资源中保存生产数据、住客 PII、账号密码、Session、Token 或密钥。
4. 新增图片、SQL、Apifox 环境或其他资源时，同步更新本文件与文档索引，说明用途、来源、适用版本和风险。
