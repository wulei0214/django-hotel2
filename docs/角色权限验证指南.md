  员工管理菜单；直接访问 `/nightaudit/` `/finance/` `/export/staff/` 均 403；
  跨房型换房 403

### 值班经理 test_duty

## 四、权限矩阵页交叉验证

1. 超管登录 → `/permissions/`：应见 9 角色 tab + 2 预留占位（灰显）；
   餐厅/停车模块行灰显"预留"；高危动作区 7 项
2. 全选保存某角色 → 回显勾选一致；Django Admin 组编辑器同步可见
3. 在 Admin 给某组手工加非矩阵权限（如 auth 的组查看权）→ 回矩阵页保存 →
   该权限**不被清空**（前后台一致性）

## 五、注意事项

- 测试账号含完整身份链（任职关系），符合员工门禁；测试结束请改密或禁用
- 夜审每天只能执行一次（幂等守卫）；重复测试请先删除当日夜审记录或换营业日
- 敏感操作审计在 `logs/audit.log`（含 PII reveal、冲账、反结账、夜审、权限变更）
