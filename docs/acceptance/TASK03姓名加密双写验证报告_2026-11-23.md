## 3. 加密与盲索引行为

```
加密后密文前缀: gAAAAABrBCzDpOWft0RfBL76...   ← Fernet 格式（gAAAAA 前缀）
解密回原文一致: True  ('欧阳修')
同姓名 HMAC 确定: True
不同姓名 HMAC 不同: True
HMAC 长度: 64（满足 64 位字段）
```

- Fernet 密文带时间戳前缀，**同一明文每次加密结果不同**（这是 Fernet 特性，符合预期）；
- HMAC-SHA256 是确定性摘要，**同姓名恒等**（支撑精确检索/去重）。

## 6. 明文列现状（澄清，非缺陷）

`Guest.full_name` **仍存明文**。这是**阶段 1 的既定设计**，不是缺陷：

- 设计：「阶段 1 = 双写（明文保留，观察期受控回滚）；读路径与明文列退役由负责人批准后的阶段 2 迁移完成」；
- 理由：`icontains` 模糊检索是前台核验核心功能，本阶段保留在明文列上；模糊→精确的检索语义变化属**产品决策**，不在本阶段擅自切换。

→ **阶段 2 未启动**，符合治理现状（本次拦截只涉及揭示权限，未动阶段 2）。
