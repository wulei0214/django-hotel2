## 4. 复核发现的文档错误（3 处）

### 4.1 §0 分中心表合计 93 但正文写 90（见 §1.3）

- 表内实算 93；正文「缺口合计 90 项」；且 `RPT-07/08` 从未存在（虚增 2），NA/HK 各漏记 1（V13-02 新登记未同步）。
- **影响**：`92 = 90 + 2` 这个分母无法复现；后续所有基于 92 的统计（46/46）偏差 1。

### 4.2 §0.2「开放 46」不成立

- 无论按 91 计分缺口（46 关闭）还是按复核后 41 开放，都得不到 46。
- `46 = 92 − 46` 是「把错误的 92 减去已关闭 46」得到的，**不是枚举结果**。

### 4.3 P1 开放「清零」表述需限定

- 按条目行标记：P1 开放确为 0 ✅（RES-04/05 于 `0d67e0b`、HK-10 于 `a04ade5`、ST-02/RES-06/RPT-01/NA-13 前批已关）。
- 但 `ST-04`、`G360-05`、`FIN-08` 三项标为 `CODE_DONE_TEST_PENDING`，若按任务书口径它们属「代码完成缺测试」，**不等同于 DONE**，也不应算作 P2 登记了事。本报告已如实分列。
