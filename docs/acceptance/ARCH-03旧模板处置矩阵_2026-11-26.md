## 一、扫描方法

对 `templates/` 下 **37 个**模板逐个核查六类引用（任务书 §3.2 要求的全部维度）：

1. **URL / View 引用**：模板名在 `hotelapp/views.py` 等代码中的字面量引用（`render(request, "xxx.html")`）。
2. **extends / include**：模板中 `{% extends "..." %}` / `{% include "..." %}` 的被包含关系。
3. **JS 与静态资源**：`static/` 下对模板名字面量的引用。
4. **模板继承**：由 #2 推导。
5. **测试引用**：测试文件中对模板名字面量的引用。
6. **管理中心替代页面**：`apps/api/pages.py` 的 `MANAGEMENT_CENTERS` 注册表 + 旧模板与新中心的业务域对应。

**处置标记只允许三种**：`KEEP / MIGRATE / DELETE`。
