## 六、异常注入与清理说明

- 异常注入方式：`unittest.mock.patch` 替换 `report_center.{occupancy,revenue,adr}_report` 的 HTTP 返回载荷，**只改报表输出**，复算仍读真实源表；
- 数据构造：`TestCase` 事务内建 `RoomTypeInventory` / `Folio` / `LedgerEntry` / `Reservation` 夹具，测试结束随事务回滚；
- 未污染 dev 业务数据：MySQL 用例跑在 `create_test_database` 创建并在结束时销毁的测试库（日志含 `Creating/Destroying test database`）；
- 真实数据复算（§四）为只读命令，不写入任何业务表。
