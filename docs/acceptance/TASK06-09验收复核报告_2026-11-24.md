| `apps.reservations.test_mysql_concurrency` | **2** | **OK** | 0 | 预订并发（MySQL 专属） |
| **合计** | **35** | **全 OK** | — | — |

### 1.3 这些用例在 SQLite 上是被跳过的

`apps/inventory/test_room_conflict_concurrency.py` 第 112-113 行：

```python
if connection.vendor != "mysql":
    self.skipTest("唯一键仲裁仅 MySQL 为权威来源（SQLite 无部分索引语义）")
```

→ **只有 MySQL 跑才算真验证**。本轮已实证这 7 例在 MySQL 真实执行并通过。

> 这也解释了双引擎全量中 SQLite skip=29 vs MySQL skip=3 的差值：那 26 项正是此类引擎专属用例，**不是失败**。
