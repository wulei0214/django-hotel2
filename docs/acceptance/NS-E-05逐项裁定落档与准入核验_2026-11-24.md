### 3.2 条件 0 阻断详情（**最高优先级缺陷**）

```
File "apps/api/front_desk.py", line 1345
    @api_guard
    ^
IndentationError: expected an indented block

File "apps/api/front_desk.py", line 1347
    @_front_desk_action_required("billing.payment_collect")
```

**根因**：`front_desk.py:1344` 的 `def _front_desk_action_required(permission_code):` **函数体为空**，装饰器直接跟在下一行；且该函数在与使用它的装饰器（L1347-1348）之间存在定义/调用顺序问题。

**影响**：
- `manage.py check` 失败；
- **所有测试无法运行**（Django 无法导入 `apps.api.urls`）；
- 使「双引擎验证」这一准入条件根本无法证明。

**严重性：P0 阻断。** 按裁定「任何一项未通过核验，都不得以代码已就绪或测试全绿为由跳过准入」，此项不修复则 Retention 与 FIN-06/MB-11 **均无法进入合入流程**。
