## 三、规则与白名单策略

- 高信号规则：`aws-access-key`、`github-token`、`private-key-block`、
  `db-uri-with-password`、`bearer-token`、`django-secret-key`、历史失效口令字面量。
- 通用赋值规则：`password|passwd|pwd|secret|token|api_key|apikey|access_key` + 带引号值（≥8 字符），
  允许前缀下划线（`_TEST_PW_*` 这类常量同样算明文）。
- 白名单只能按（文件, 规则）精确豁免，`rule` 为空或 `*` 直接拒绝加载；
  每条必须填 `reason/reviewed_by/reviewed_at`。**本轮白名单条目数 = 0**。

## 六、顺带修复的工具缺陷

`scan_secrets.py` 在 Windows 下对"仓库外路径"执行 `os.path.relpath` 会抛
`ValueError: path is on mount 'C:', start on mount 'F:'`，导致本地对临时目录做
反向验证时崩溃。已改为 `_display_path()`：仓库内给相对路径，仓库外给绝对路径。
