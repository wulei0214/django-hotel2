### 2.1 MySQL 库名问题（一次排障记录）

本机 `hotelhotel` 授权（现取）：

```
GRANT ALL PRIVILEGES ON `hotel`.*      TO `hotelhotel`@`127.0.0.1`
GRANT ALL PRIVILEGES ON `test_hotel`.* TO `hotelhotel`@`127.0.0.1`
```

Django 测试会在 `NAME` 前加 `test_` 前缀：

| `DJANGO_DB_NAME` | Django 实际请求 | 结果 |
|---|---|---|
| `test_hotel` | `test_test_hotel` | ❌ `1044 Access denied` |
| **`hotel`** | **`test_hotel`** | ✅ 已授权，成功 |

→ 故设 `DJANGO_DB_NAME=hotel`，由 Django 自行创建 `test_hotel`。**未扩张任何授权**，符合 AGENTS.md「不追加 `test_%` 授权」。

> CI 用 root 账号 + `hotel_ci` 库，与本机路径不同，两者均合规。
