### 4.2 夜审员逐格（本次受关注岗位）

| 场景 | 端点 | 期望 | 实测 | 判定 |
|---|---|---|---|---|
| S1 退款执行 | POST `/api/v1/billing/refunds/999999/execute` | deny | **403** | ✅ |
| S2 退款审批 | POST `/api/v1/billing/refunds/999999/approve` | deny | **403** | ✅ |
| **S3 夜审执行** | POST `/api/v1/night-audit/run`（date=1900-01-01） | allow | **409** | ✅ |
| S4 电话揭示 | POST `/api/v1/guests/51/phones/47/reveal` | deny | **403** | ✅ |
| S5 房态放行 | POST `/api/v1/housekeeping/rooms/999999/status` | deny | **403** | ✅ |
| S6 财务视图 | GET `/api/v1/billing/refund-liabilities` | deny | **403** | ✅ |
| S7 报表导出（非法码） | GET `/api/v1/reports/export?report=__invalid__` | allow | **400** | ✅ |
| S7b 报表导出（occupancy） | GET `/api/v1/reports/export?report=occupancy` | deny | **403** | ✅ |
| S8 审计导出 | GET `/api/v1/audit/export` | deny | **403** | ✅ |
| PAGE 夜审中心 | GET `/manage/night-audit/` | allow | 可访问 | ✅ |

**S3 得 409 的含义**：权限门禁**已通过**（否则 403），业务层因「营业日 1900-01-01 不存在」而拒绝。这正是我们想验证的「授权生效且不误关账」。与 2026-11-22 结论一致。
