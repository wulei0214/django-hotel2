## 四、自动化配方（可复核）

- 可靠点击 = 只读 evaluate 量坐标 → cua.click → 效果验证；离屏元素先 scrollIntoView + 稳定双采样（防平滑滚动 stale 坐标）。
- `window.prompt`（开班/关班）IAB 无法自动化 → 环境准备阶段 API 等价（记为 setup，非测试通过项）；`window.confirm` 用 getJsDialog 同轮应答。
- 登录/退出在点击不可靠时用页面表单 POST（环境准备路径）。
- 浏览器点击与 API 数据准备分离：API 直接创建的数据不计为浏览器业务操作通过。
