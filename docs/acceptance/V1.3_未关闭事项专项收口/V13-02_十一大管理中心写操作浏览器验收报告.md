## 一、验收方法（三重验证，无 API 代替浏览器）

每个写操作均在**真实浏览器会话**内完成：

1. **UI 操作**：Playwright 驱动 headless Chromium，点击真实页面按钮/表单（隐藏表单、抽屉、任务池行按钮），对话框（`window.confirm`/`window.prompt`）真实应答；
2. **API 响应捕获**：浏览器页面上下文同会话捕获每次写请求的 HTTP 状态与响应体；
3. **DB 核对 + 审计核对**：独立只读 Django 脚本（`db_verify_p36.py` / `db_verify_p7.py`）核对业务事实表与 `AuditEvent` 追加链。

禁用捷径：全程不直接 curl API 产生业务写；所有业务写均由 UI 触发（Phase 7 拒绝场景为岗位权限取证，按任务书允许在浏览器会话内对高危端点发起真实请求并取证 403）。
