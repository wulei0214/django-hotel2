## 二、工具自验（合成样本，8 行含 1 行非日志文本）

样本覆盖：旧入口 POST 410×2 + 410×1（python-requests×2、OkHttp×1）、旧入口 GET 405×1、
旧入口 PUT 410×1、标准入口 POST 201×1、标准入口 GET 200×1。

```
> python scripts/walkin_410_stats.py <样本>            # 默认 POST 口径
旧入口 POST 命中 3 次；其他方法合计 2 次（GET 1, PUT 1）
标准入口命中 2 次（按方法：{'POST': 1, 'GET': 1}）
旧入口 POST 状态码分布：{'410': 3}
旧入口 POST 按日：{'19/Nov/2026': 3}
旧入口 POST 调用方 UA 族：{'python-requests': 2, 'OkHttp(Android)': 1}
旧入口 POST 不同来源数（IP 短哈希去重）：3
退出码 = 0

> --method ALL：旧入口全方法 5 次（410×4、405×1），按日/UA 相应扩展，退出码 0
> 空目录：无可解析日志行……退出码 = 2
```

对照判读：POST 口径下 GET 405 / PUT 410 均未混入主计数；标准入口两条独立统计；
来源去重 3 = POST 调用方实际去重数（非全样本 4），口径隔离正确。
