## 维护规则
- 新建或实质修订文件采用 `主题_YYYY-MM-DD.md`。
- 文件名日期后缀表示本轮归档核对/版本整理日期，不代表原始创建日期；原始日期无法核实的历史资料不得据此推断其创建时间。
- 需求、决策、实施、测试和验收文档职责不同，不因相似而删除唯一证据。
- 删除前核实 Markdown 引用、代码/CI 路径及审计价值。

- 本轮统一为缺少日期后缀的 Markdown 文件追加 `_2026-11-10`，含义为归档核对日期；历史审计文件原始内容和证据不变。
