## 文档状态约定

- **正式决策**：负责人确认后生效，代码必须遵循。
- **正式验收基线**：规定验收门槛、证据和最终判定；不代表项目已通过验收。
- **现状说明**：描述指定 SHA 的实际代码；代码变化后更新。
- **实施方案/评审稿**：目标态要求，不代表功能已实现。
- **测试记录**：仅对记录的 SHA、环境、数据库和日期有效。
- **历史归档**：供追溯，不作为当前功能说明。

每次 PR 同步更新受影响文档。涉及页面/API/模型/权限的改动必须注明已实现、部分实现、未实现或待验收。不得将目标态写成现状，也不得为消除文档冲突删除正式决策、migration、审计或账务历史。
