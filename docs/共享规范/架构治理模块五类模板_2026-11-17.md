# 架构治理模块五类模板（派发/门禁签署/证据归档/回滚演练/批次验收）

> 文档编号：GOV-TPL-001 ｜ 类型：GOVERNANCE ｜ 状态：ACTIVE ｜ 版本域：跨版本 ｜ 业务模块：架构治理
> 依据：排期 V2.0 GOV-06——财务模块经验固化为五类正式模板后，方进入预订与入住退房（模块③）、房态与库存（④）、顾客与会员（⑤）治理。
> 经验来源：财务模块全程真实产物——GOV-01~06 主线文档、阶段D批次2~4.5 实施记录、GOV02/GOV03 签署与核验、G14 R3 演练、MC 整改与部分端点收敛证据。
> 效力：模块③④⑤的治理交付必须按本模板组织；模板本身按"整体重写制"演进。

## 一、派发单模板

**填写责任方**：派发方（负责人或授权主控代理）。**必填**，缺项不得开工。

| 字段 | 说明 | 财务实例（摘录） |
|---|---|---|
| 基线 | 派发时 main SHA + 工作区在途清单（多 AI 并行隔离要求：显式 pathspec / pathspec-from-file 提交） | 批次4 派发 @8467012 |
| 规范依据 | 宪法 §引用 + 模块设计文档 §引用 + 裁定编号（NS 前缀） | 设计六份 fe579479 + GOV-02 裁定 1~5 |
| 范围 | 本批次做什么/明确不做什么（冻结项列举） | 批次3=受控入口与归档层；不做 D1 停写 |
| 修改等级 | L1~L4 判定 + 依据（宪法 §11） | 阶段D 迁移=L4 |
| 测试计划 | 正常+异常双路径；SQLite/MySQL 双引擎口径；证据日志命名 | test_legacy_order_map 26 项 |
| 交付要求 | 实施记录结构 + 证据归档路径 + 需同步的文档清单 | 批次记录 + evidence/*.log |

## 二、门禁签署模板

**填写责任方**：核验=独立审查/负责人；签署=负责人（不可代判）。代录按 GOV02-SIGN-20261116 先例（授权原文入档 + 决定权归属声明 + 效力边界如实）。

| 字段 | 说明 |
|---|---|
| 准入编号 | GOV-xx 或批次号 |
| 检查项清单 | 逐项三态：满足 / 部分满足（附缺口） / 未满足 |
| 证据列 | 每项绑定的 evidence 文件与 SHA |
| 结论 | 全部满足才可签署通过；部分满足须列明补齐条件 |
| 签署栏 | 负责人 / 日期 / 授权代录时附授权原文 |

财务实例：GOV-03 八项准入（5 满足/2 部分满足/1 未满足 → 结论"不批准阶段 D"→ 后经授权记录转为分批实施）。

## 三、证据归档模板

**填写责任方**：开发执行方（证据生成）；复核=审查方。

| 字段 | 说明 |
|---|---|
| 文件命名 | `docgate-<主题>-<YYYYMMDD>.log`（或业务前缀）；测试证据 `test-<引擎>-<主题>-<YYYYMMDD>.log` |
| 头记录必填 | SHA（被测树绑定：含未提交变更检测标注）/ 时间 / 环境（DJANGO_* 变量）/ 命令 / 退出码 |
| 归档路径 | docs/acceptance/evidence/（只进不出；C6 门禁拦 M/D/R） |
| 基线绑定规则 | 证据 SHA ≠ 被测代码时必须在头记录标注（scripts/test_evidence.py 已内建）；历史证据不回填现值 |
| 引用纪律 | 文档引用证据必须指向已提交文件（未提交引用会被 docs 门禁 C1 拦截） |

财务实例：`docgate-partial-verification-20261116.log`（167 项全绿）、`g14-r3-backup-restore-drill-20261117.log`（100 表零差异）。

## 四、回滚演练模板

**填写责任方**：开发执行方执行；运维复核。**触发条件**：每治理批次前后；模型/迁移变更后；上线前必做。

| 步骤 | 内容 | 财务实例（G14-R3 演练） |
|---|---|---|
| 1 备份 | mysqldump 全库（含 schema+data） | 504296 bytes |
| 2 隔离还原 | 建 scratch 库导入（不触碰源库） | hotel_r3_scratch |
| 3 核对 | 逐表行数零差异（information_schema 全表遍历）+ 关键业务重算（如 Folio 余额） | 100 表差异=0 |
| 4 清理 | 删除演练库；证据归档 | dropped + evidence log |

## 五、批次验收模板

**填写责任方**：开发=实施记录；验收=负责人/独立审查。

| 字段 | 说明 | 财务实例 |
|---|---|---|
| 背景与裁定依据 | 引用裁定编号与前置门禁 | 批次4.5=FIN-01/02 负责人裁定 |
| 交付清单 | 文件级（模型/迁移/服务/测试/文档） | models.py+0035+服务+26 测试 |
| 验证表 | 正常+异常路径逐项：测试模块/结果/证据 | 26 全绿+无漂移 |
| 设计边界登记 | 实现中发现的未决取舍（两案+建议）——**不得自行裁决** | 批次4 §3.3 组合唯一 vs 回退 |
| 残项移交 | 环境边界/生产操作/人力验收项，逐条注明责任方 | 盘点回填=生产环境获得后重跑 |
