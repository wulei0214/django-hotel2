发现 docs/接口文档/openapi.json 与 PMS2 当前版本下的权威快照均为 113/115，但 GET /api/v1/billing/shifts 的 query 状态说明不一致：根目录副本包含 RECONCILED，权威快照只列 OPEN/CLOSED。根因是导出命令写入 PMS2 嵌套路径，而 workflow 只 git add docs/接口文档/openapi.json。

修复要求：根目录副本内容必须与权威快照一致；导出后同步根目录副本，并同时 add 两份文件。运行时真实可筛选值仍以 view/service 为准，不凭文档推断。
