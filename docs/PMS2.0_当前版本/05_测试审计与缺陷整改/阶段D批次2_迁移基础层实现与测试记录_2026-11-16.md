## 2. 与设计条文的对应关系

| 设计位置 | 实现要点 | 落地位置 |
| --- | --- | --- |
| 归档门禁 §4.2 第 1~2 条 | `len(名)+名+len(类型)+类型+NULL标志+len(值)+值`，4 字节大端前缀；NULL 与空串严格区分 | `legacy_checksum.encode_field()` |
| 归档门禁 §4.2 第 3~5 条 | 字符串 UTF-8 原样；金额保原字符串（`format(Decimal,"f")`，无科学计数法）；时间「原始值 + UTC ISO8601」双值同编 | `_value_bytes()` |
| 归档门禁 §4.2 第 6~8 条 | 行摘要 SHA-256；行摘要按**主键数值升序**长度前缀拼接；整表摘要 SHA-256 | `row_digest()` / `table_digest()` |
| 归档门禁 §4.2 第 9 条 | 元数据登记算法版本/行数/min-max 主键/计算时间/执行人 | `build_metadata()` |
| 归档门禁 §4.2 实现约束 | Python 侧计算，**不依赖 DB SHA2**，规避 SQLite/MySQL 方言差异 | 全模块无 SQL 调用 |
| 迁移方案 §5.2 批次字段 | `batch_uid` / `approved_by` / `approved_at` / `approval_basis` / `scope_property` / `scope_source_models` / `scope_record_range` / `executed_by` / `status` | `LegacyMigrationBatch` |
| 迁移方案 §5.2 状态机 | PENDING→ACTIVE/CLOSED/REJECTED；ACTIVE→CLOSED；其余拒绝；CLOSED 终态不可复活 | `_ALLOWED_TRANSITIONS` + `save()` |
| 迁移方案 §5.2 R6-03 N12 | QuerySet 层 `update/delete/bulk_update/bulk_create` 一律拒绝（默认管理器） | `ImmutableBatchQuerySet` |
| 迁移方案 §5.2 SoD | `approved_by ≠ executed_by`，DB CheckConstraint 强制 | `ck_legacy_batch_sod` |
| 迁移方案 §5.2 R6-03 凭证 | 载荷 4 字段 + `django.core.signing`（HMAC-SHA256，专用 salt `legacy_migration.execution`）+ `max_age=900` | `mint_credential()` / `load_credential()` |
| 迁移方案 §5.2 R6-03 nonce | 验证通过即写入 AuditEvent（`billing.legacy_migration_auth`），nonce 列唯一 → 重放被 DB 拒绝 | `_consume_nonce()` + `AuditEvent.nonce` |
| 迁移方案 §5.2 绑定与范围 | 批次一致 / 执行人一致 / status=ACTIVE / 记录 ⊆ scope（区间或 id 清单） | `_check_binding()` / `assert_record_in_scope()` |
| 迁移方案 §5.2 拒绝审计 | 任何拒绝写 `billing.legacy_migration_denied` | `record_denial()` |
