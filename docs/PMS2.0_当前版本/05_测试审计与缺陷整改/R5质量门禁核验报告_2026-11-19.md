1. **MC-006-R1 / DEF-M3-2-ISO-01**：`apps/api/test_housekeeping_workflow.py::MaintenanceTicketWorkflowTests.test_full_maintenance_chain_restores_inventory_only_after_acceptance` 在 MySQL 包序下 400 != 200（本轮 1747 项唯一失败、CI tests 红灯根因；隔离复跑 OK，多个不相关前置模块均可触发）。移交主会话修复测试隔离（fixture/sequence 口径），**不得**为绿灯删测试。

3. **本机 MySQL 容量边界**：`max_connections=20`（含并行会话常驻连接 11 条）在并发全量下偶发 `OperationalError 1040 Too many connections`（23:08 轮 2 例，本轮复跑未复现）。非业务缺陷；生产部署容量参数已在《性能优化与生产部署升级说明》域覆盖，本机多会话并行跑全量前建议核对空闲连接数。
4. **test_hotel 本地命名竞争**：本轮 23:28 启动因并行会话 DROP/CREATE test_hotel 竞争中断（1049）。CI 已用独立库名 `test_hotel_ci`；建议本地多会话约定测试库命名隔离（如 `test_hotel_<batch>`）或错峰执行全量回归。
