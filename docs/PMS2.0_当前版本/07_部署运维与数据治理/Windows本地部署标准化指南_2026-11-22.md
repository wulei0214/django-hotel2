## 一、环境要求

| 组件 | 要求 |
|---|---|
| OS | Windows 10/11，Git Bash 为推荐 shell |
| Python | 3.9，仓库 .venv 虚拟环境 |
| 数据库 | MySQL 8（dev 库 hotel）；SQLite 仅用于测试 |
| Node.js | ≥16，仅浏览器 E2E 需要（scripts/browser_tests 下 npm install），可跳过 |

## 二、全新环境安装

1. `git clone https://github.com/wulei0214/django-hotel2 && cd django-hotel2`
2. `python -m venv .venv && .venv/Scripts/python.exe -m pip install -r requirements.txt`
3. 编写 `.env`（键：DJANGO_DB_ENGINE=mysql、DJANGO_DB_NAME=hotel、DJANGO_DB_USER、DJANGO_DB_PASSWORD 等；凭据不入仓）。

## 三、数据库迁移与角色初始化

先加载环境（铁律，settings 不自动读 .env）：

```bash
set -a && source .env && set +a
python manage.py migrate
```

九角色测试账号（test_front / test_duty / test_finance / test_owner / test_housekeeping / test_nightaudit / test_fnb / test_fnbsup / test_parking）：

- `getpass` 在 Windows 无 TTY 下会阻塞，必须走 sanctioned 注入运行器 `scripts/seed_roles_inject.py`（从 r6_env.txt 读 ACCEPT_PASSWORD）或 shell 内 monkeypatch。
- 口令纪律：测试账号口令唯一载体 `scripts/r6_env.txt`（gitignored），键 TEST_ACCOUNT_PASSWORD / ACCEPT_PASSWORD；轮换经负责人批准并在该文件留痕。

## 四、启动与浏览器访问

```bash
# 生产形态（waitress，与验收环境同构）
.venv/Scripts/python.exe -c "from waitress import serve; from hotel.wsgi import application; serve(application, host='127.0.0.1', port=8000, threads=8)"

# 开发形态
.venv/Scripts/python.exe manage.py runserver
```

入口 `http://127.0.0.1:8000/login/`；管理中心 `/manage/<center>/`；前台 `/checkin/`；首登强制改密（同口令重提交通过）。

## 五、自动化测试与门禁

```bash
# 快速回归（SQLite）
DJANGO_ENV=test DJANGO_DB_ENGINE=sqlite python manage.py test -v 1

# MySQL 权威全量（错峰：同一共享环境同一时刻仅一个全量进程；登记执行人/库名/命令/退出码）
set -a && source .env && set +a
unset DJANGO_PLATFORM_ADMIN_USERNAME DJANGO_PLATFORM_ADMIN_PASSWORD
DJANGO_ENV=test python manage.py test --settings=hotel.settings -v 1
```

纪律：结果写入 docs/acceptance/evidence/*.log 并头部登记；SQLite 全绿不替代 MySQL 权威（锁/约束/并发以 MySQL 为准）。

## 六、本地备份与恢复

```bash
mysqldump -h127.0.0.1 -u<user> -p hotel > backups/hotel-YYYYMMDD.sql
mysql -h127.0.0.1 -u<user> -p hotel < backups/hotel-YYYYMMDD.sql   # 恢复=整库导入
```

## 七、常见问题排查（本轮实测踩坑）

| 症状 | 根因 | 处置 |
|---|---|---|
| seed 挂起 | getpass 无 TTY 阻塞 | 用 §三 sanctioned 注入运行器 |
| 测试连库 Access denied | .env 未 source | `set -a && source .env && set +a`；SQLite 另加 DJANGO_DB_ENGINE=sqlite |
| MySQL 全量身份域假失败 | 平台白名单变量泄漏 | unset DJANGO_PLATFORM_ADMIN_USERNAME/PASSWORD |
| pre-commit 连 github 超时 | 代理 | 本地 ruff+black 后 `--no-verify` 提交 |
| docs 门禁 C6 拦截证据修改 | 证据文件 M/D 状态 | 正当修改按「更新须与修复同提交」登记 c6_known 基线 |
| 浏览器 E2E 登录失败 | 测试口令过期 | 以 scripts/r6_env.txt 当前值为准，勿猜、勿擅自轮换 |
