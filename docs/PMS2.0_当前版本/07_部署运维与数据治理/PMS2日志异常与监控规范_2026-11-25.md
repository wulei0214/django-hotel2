## 1. 已实现（有代码与测试）

### 1.1 请求关联标识

- 中间件：`apps/core/request_context.RequestIDMiddleware`（已挂载于 `MIDDLEWARE`，位于 Session 之后）。
- 规则：入站 `X-Request-ID` 仅在 `^[A-Za-z0-9._:-]{1,64}$` 时复用；否则生成 16 位十六进制。
- 响应：回写 `X-Request-ID`，客户可与服务端日志对账。
- API 响应体 `meta.request_id` 与 `AuditEvent.request_id` 使用同一来源。

### 1.2 结构化日志

- Formatter：`apps/core/logging_utils.JsonFormatter`，输出单行 JSON。
- 字段：`timestamp`、`level`、`logger`、`message`、`request_id`、`property_id`、`actor_id`、`event`、`error_code`、`exception_type`（有异常时）。
- logger 与落点：

| logger | handler | 用途 |
|---|---|---|
| `hotel.audit` | `audit_file` | 业务审计（前台/客房/审批动作） |
| `hotel.api` | `request_file` | API 层异常与拒绝 |
| `hotel.core` | `request_file` | Outbox / 基础设施 |
| `hotel.billing` | `audit_file` | 支付/退款/补偿 |
| `django.request` | `request_file` | Django 请求异常 |

> 整改前 `hotel.api` 等无 handler，ERROR 静默丢失（已修复，见 `df6aef9`）。

### 1.3 脱敏规则

`redact()` 对以下内容做不可逆遮盖：

| 类型 | 规则 | 取代 |
|---|---|---|
| 手机号 | `(?<!\d)1\d{10}(?!\d)` | `<redacted-phone>` |
| 身份证 | 18 位（末位可 X） | `<redacted-id>` |
| 凭据键值 | password/passwd/pwd/secret/token/api_key/credential | `<redacted>` |

审计 `before/after` 由调用方保证脱敏；PII 揭示必须走受控服务并留审计理由。

## 2. 异常分类

| 类别 | 表现 | 响应 |
|---|---|---|
| 参数错误 | `ApiError("VALIDATION_ERROR")` | 400 + 字段错误 |
| 权限拒绝 | `PERMISSION_DENIED` | 403 |
| 未认证 | `AUTHENTICATION_REQUIRED` | 401 |
| 业务状态冲突 | `BUSINESS_CONFLICT` | 409 |
| 资源不存在/越权 | `RESOURCE_NOT_FOUND` | 404（不泄露存在性） |
| 限流 | `RATE_LIMITED` | 429 + `Retry-After` |
| 系统异常 | 未预期异常 | 500 + 通用文案，堆栈只进日志 |

纪律：不得把堆栈、SQL、内部路径返回客户端。

## 3. 关键指标定义（已定义，采集未部署）

| 指标 | 定义 | 来源 | 建议阈值 |
|---|---|---|---|
| API 错误率 | 5xx / 总请求 | `request_file` JSON 统计 | >1% 持续 5 分钟告警 |
| API P95 延迟 | 请求耗时 P95 | 需新增耗时字段（未实现） | >2s 告警 |
| 支付失败率 | FAILED / 总支付 | `billing.*` 审计 | >5% 告警 |
| 退款长期未处理 | PENDING 超 24h 数量 | `Refund` 查询 | >0 工单 |
| Outbox 积压 | PENDING+RETRY 数量 | `OutboxEvent` 查询 | 持续增长告警 |
| Outbox 死信 | DEAD 数量 | 同上 | >0 立即处理 |
| 补偿任务积压 | PENDING `PaymentCompensationTask` | 查询 | >10 告警 |
| 审批积压 | PENDING `ApprovalRecord` | 查询 | >20 告警 |
| 夜审失败 | FAILED `NightAuditRun` | 查询 | >0 告警 |
| 数据库连接 | 活跃连接/上限 | 需平台采集 | >80% 告警 |

**状态**：指标定义完成；采集与告警平台 `PRODUCTION_PENDING`（未部署 Prometheus/Grafana/Sentry）。延迟耗时字段尚未实现，属 P2。
