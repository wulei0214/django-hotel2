## 1. 分层边界（强制）

```
业务 Service（apps/*/services*.py）
   ↓ 只调用内部接口，不直接发 HTTP
Integration Service（适配层，待建）
   ↓ 统一认证/签名/超时/重试/幂等/脱敏
Provider Adapter（一渠道一实现）
   ↓
外部系统（OTA / 公安 / POS / 停车 / 发票 / 支付 / 门锁）
```

禁止事项：

1. 业务模块直接 `requests.post` 打外部接口。
2. 在数据库事务内做外部网络调用（长事务 + 不可回滚副作用）。
3. 外部响应未校验即写入业务事实。
4. 把密钥、商户号、证书写入代码或日志。

## 4. 适配层接口契约（新渠道接入时必须遵守）

每个 Adapter 至少实现：

| 关注点 | 要求 |
|---|---|
| 认证 | 凭据从环境/密钥管理读取，不落库明文、不进日志 |
| 签名 | 请求/回调均验签；签名覆盖时间戳与 nonce（防重放） |
| 超时 | 连接/读取超时显式设置（建议 3s/10s） |
| 重试 | 仅对幂等操作有限重试，指数退避；非幂等操作不得自动重试 |
| 幂等 | 商户订单号/事件 ID 唯一键落库；重复回调返回既有结果 |
| 校验 | 金额、币种、订单归属、物业一致性全部服务端复核 |
| 失败处理 | 可恢复 → 补偿任务；不可恢复 → 死信 + 人工清单 |
| 脱敏 | 日志只记外部单号后 4 位与状态 |
