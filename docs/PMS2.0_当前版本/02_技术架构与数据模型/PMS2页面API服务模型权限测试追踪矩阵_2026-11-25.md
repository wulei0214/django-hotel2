## 0. 列定义

| 列 | 含义 |
|---|---|
| 入口 | 页面路径或 API 路径 |
| Service | 承载业务规则的服务函数（状态机与事务边界在此） |
| Model | 权威数据归属（单一事实源） |
| 权限 | 服务端最终校验的权限码 / 数据范围 |
| 审计 | 落 AuditEvent 的动作码 |
| 测试 | 自动化用例落点 |
