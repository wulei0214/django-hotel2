### 字段逐项说明

| 字段 | 候选值 | 依据 |
|---|---|---|
| key | `payment_collect` | 稳定唯一；与现注册表命名风格一致（动宾式：`refund_request`/`cash_movement_manage`） |
| codename | `billing.payment_collect` | ✅ `billing` app_label 存在（Django Permission 可解析）；与退款三码同域 |
| module | `finance` | 现注册表 finance 域已登记 7 码（refund 三码 + 冲销两码 + 班次两码），归属一致 |
| risk | `high` | 资金流入动作；误操作直接影响账本事实（虽可冲销但需审批链） |
| requires_reason | `False` | 收款是正常业务动作，非敏感/异常操作；错收款走红字冲销审批链（`billing.reverse_entry` + `billing.reversal_approve`），不由收款侧承担 reason |
| requires_confirm | `True` | 对齐前台现网交互（"请确认这笔款项已经实际收到"二次确认，`frontdesk.js` 已实现）；资金动作防误触 |
| note | 见上 | 七要素齐备：动作（收款）、范围（本物业 OPEN MASTER Folio）、限制（不携带读权限/与退款分离/现金班次守卫） |
